# 한별소프트 비용 처리 규정

**시행 2026-01-01 · 경영지원팀**

---

## 1. 목적과 적용 범위

이 규정은 한별소프트 주식회사의 법인카드 사용분과 임직원 경비 정산의 처리 기준을 정한다.

적용 대상은 다음과 같다.

- 법인카드 사용분 전체
- 임직원이 선지출한 뒤 정산을 신청한 경비
- 프로젝트에 직접 부과되는 비용

## 3. 증빙 기준

### 3.1 제출 대상

법인카드 사용분은 사용일로부터 **10영업일 이내**에 증빙을 제출한다. 제출은 증빙 대장에 등록하는 것으로 갈음한다.

증빙 대장에는 아래 다섯 항목을 적는다.

- 승인일자
- 가맹점
- 금액
- 제출자
- 증빙파일명

### 3.2 증빙 서류

원칙은 신용카드 매출전표다. 매출전표를 받지 못한 경우 세금계산서 또는 현금영수증으로 대신할 수 있다.

접대비는 금액과 무관하게 **참석자 명단**을 함께 제출한다.

### 3.3 제출 면제

**정기결제 계약 건은 증빙 대장 등록 대상이 아니다.** 계약서와 월 청구서가 경영지원팀에 보관되어 있어 매월 같은 증빙이 반복 등록되는 것을 막는다.

면제 대상 계약은 아래와 같다. 이 목록에 없는 정기결제는 면제되지 않는다.

| 가맹점 | 계약 | 청구 주기 |
|---|---|---|
| Microsoft 365 Business | HB-SW-2024-011 | 매월 1일 |
| Adobe Creative Cloud | HB-SW-2025-003 | 매월 5일 |
| Slack Technologies | HB-SW-2025-007 | 매월 10일 |

면제 건은 대사 결과에서 **증빙 누락으로 분류하지 않는다.** 별도 항목으로 표기한다.

## 4. 대사 기준

### 4.1 대사 키

법인카드 명세와 증빙 대장은 아래 세 항목이 모두 같을 때 같은 건으로 본다.

> **승인일자 · 가맹점 · 금액**

제출자와 카드 사용자는 대사 키가 아니다. 확인용으로만 쓴다.

### 4.2 불일치 유형

불일치는 아래 세 유형으로만 분류한다. 세 유형에 들어가지 않는 것은 불일치가 아니다.

| 유형 | 정의 | 조치 |
|---|---|---|
| 증빙 누락 | 명세에는 있고 대장에는 없다 | 사용자에게 증빙 제출을 요청한다 |
| 금액 불일치 | 승인일자와 가맹점은 같고 금액이 다르다 | 매출전표 원본으로 금액을 확정한다 |
| 중복 증빙 | 같은 건이 대장에 두 번 이상 올라와 있다 | 나중 등록분을 취소한다 |

### 4.3 행 수 판정 금지

**명세와 대장의 행 수 차이로 불일치 건수를 판정하지 않는다.** 면제 건과 중복 건이 서로 상쇄되어 행 수 차이가 실제 불일치 건수와 달라진다.

판정은 4.1의 대사 키로만 한다.

## 6. 비용 코드와 프로젝트 코드

### 6.1 부서 비용

부서 예산으로 처리하는 비용은 §2의 계정 코드와 부서 코드를 적는다.

### 6.2 프로젝트 비용

특정 프로젝트에 직접 부과되는 비용은 **프로젝트 코드가 반드시 필요하다.** 프로젝트 코드 없이는 정산 문서를 마감할 수 없다.

프로젝트 코드 형식은 다음과 같다.

```
PRJ-YYYY-NNN
```

2026년 진행 중인 프로젝트는 아래와 같다.

| 프로젝트 코드 | 프로젝트 |
|---|---|
| PRJ-2026-001 | 대한제조 MES 고도화 |
| PRJ-2026-002 | 서울여객 예약시스템 재구축 |
| PRJ-2026-003 | 한빛금융 데이터 이관 |

프로젝트 비용으로 볼 수 있는 것은 출장 교통비·숙박비, 프로젝트 전용 소프트웨어 구매, 고객사 대상 접대비다. 판단이 서지 않으면 **처리자에게 프로젝트 코드를 확인한 뒤** 진행한다.

## 7. 문서 작성 기준

### 7.1 표준 양식

월말 정산 결과는 **월말 법인카드 정산 보고서** 표준 양식으로 작성한다. 양식은 경영지원팀이 배포한 `비용처리_표준양식.docx` 하나만 쓴다.

### 7.2 필수 항목

아래 항목이 하나라도 비면 문서를 마감하지 않는다.

- 문서번호 · 작성일 · 작성자 · 작성부서 · 대상기간
- 명세 건수와 합계
- 대장 건수와 합계
- 증빙 면제 건수와 합계
- 불일치 건수와 유형별 목록
- 프로젝트 비용의 프로젝트 코드
- 승인란

### 7.3 워터마크

정산 보고서는 사외 반출 금지 문서다. **모든 쪽에 「내부문서 · 한별소프트」 워터마크를 넣는다.**

### 7.4 문서번호

```
HB-EXP-YYYYMM-NN
```

`YYYYMM`은 대상 월, `NN`은 해당 월의 발행 순번이다.
