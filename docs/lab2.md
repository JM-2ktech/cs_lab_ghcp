## 단계

### A. 이미 갖고 있는 것을 봅니다

1. **Preview** 에서 아래를 그대로 묻습니다.

   ```
   지금 당신이 쓸 수 있는 스킬이 무엇인지 직접 확인해서 목록으로 알려주세요.
   ```

    ![미리 보기 입력창에 스킬 목록을 묻는 문장을 넣은 화면](../assets/lab2/lab2-01.png)

2. 사전에 정의된 스킬의 이름과 설명이 표시됩니다.

    ![촬영: 내장 스킬 목록](../assets/lab2/lab2-02.png)

3. `analyzing-xlsx` 가 있습니다. **Lab 1에서 xlsx를 처리했던 스킬이 이것입니다.**

4. 하나의 스킬을 지정해서 내용을 확인합니다.

   ```
   search-before-answer 스킬의 내용을 보여주세요.
   ```

5. 답을 읽습니다. **마크다운으로 적힌 행동 규칙**입니다. 

    ![촬영: 내장 스킬 본문](../assets/lab2/lab2-03.png)

    {: .important }
    **Skill은 새로 배우는 개념이 아닙니다.** 이미 자연스럽게 적용되어 있었고, 사용자 정의 스킬을 제작해봅니다.

### B. 우리 회사의 방법을 씁니다

{: start="6" }
6. 메모장이나 편집기를 엽니다. 파일 이름을 `SKILL.md` 로 합니다.

7. 아래를 그대로 붙여넣습니다.

   ```markdown
   ---
   name: expense-reconcile
   description: 법인카드 명세와 증빙 대장을 대사하고 회사 표준 양식으로 정산 문서를 만든다
   ---

   # Expense Reconciliation

   ## Purpose

   법인카드 명세와 증빙 대장을 대사하여 불일치를 찾고,
   회사 표준 양식의 정산 문서를 작성한다.

   ## Procedure

   1. 두 파일을 승인일자·가맹점·금액으로 맞춘다.
   2. 맞지 않는 건을 증빙 누락 · 금액 불일치 · 중복 증빙 세 유형으로 나눈다.
   3. 규정의 증빙 면제 대상은 불일치와 별도로 집계한다.
   4. 유형별 건수와 금액 합계를 낸다.
   5. 프로젝트 비용이면 프로젝트 코드를 확인한다.
   6. resources/비용처리_표준양식.docx 를 템플릿으로 사용한다.
   7. 작성된 문서의 필수 항목과 합계를 검증한다.

   ## Output

   불일치 목록과 정산 문서를 생성한다.
   ```

    {: .note }
    맨 위 `---` 사이가 이름(name)과 설명(description)입니다. 이 두 요소는 Agent에 의해 **언제 이 Skill을 호출할지** 결정합니다. 스킬이 실제로 처리 할 본문은 호출 후 읽습니다.

    ![SKILL.md 를 UTF-8 마크다운으로 저장하는 대화상자](../assets/lab2/lab2-04.png)

    {: .warning }
    **줄머리에 공백이 들어가면 안 됩니다.** `---` 가 1열에서 시작하지 않으면 프론트매터로 읽히지 않아 업로드에서 `name` 과 `description` 이 없다고 거부됩니다.

8. 어떻게 적혀 있는지 봅니다. **「무엇을 하라」가 아니라 「이 일을 이런 방식으로 하라」** 입니다.

9. 3번 줄을 눈여겨봅니다. Lab 1에서 손으로 시켰던 「면제는 별도로 집계해 달라」의 내용이 있습니다.

## 랩의 결론
Lab 1의 Agent도 결과를 만들어냅니다. 다만 매번 다른 모양이었습니다.

| | 어디에 적나 | 무엇을 정하나 |
|---|---|---|
| 지침 | Agent 편집 화면 | 이 Agent가 **누구**인가 |
| [Knowledge](./glossary.html#knowledge) | 지식 원본 | 회사가 **무엇을 알고** 있는가 |
| [Skill](./glossary.html#skill) | `SKILL.md` 묶음 | 이 일을 **어떤 방식으로** 하는가 |

셋을 한 자리에 몰아넣을 수도 있습니다. 지침이 길어지면 됩니다. 다만 그러면 **할일이 추가 될 때마다 지침을 고치게 됩니다.** Skill은 일 단위로 붙이고 뗍니다.

내장 스킬과 우리가 만든 하나가 같은 형식인 것도 여기서 나옵니다. 

형식이 같으니 주고받을 수 있습니다. F단에서 다운로드를 진행한 `chart-builder` 는 공유가 가능합니다.
