## 랩의 결론

Agent는 「비용 처리」라는 정해진 경로 하나를 실행하지 않습니다. 자료를 보고 **이것이 무엇이고 어떤 업무에 해당하는가**를 먼저 판단합니다.

그리고 판단만으로는 대사가 되지 않습니다.

| | 무엇을 하나 | 없으면 |
|---|---|---|
| 지침 | 역할과 판단 기준 | 매번 사람이 역할을 설명한다 |
| Knowledge | 회사가 알고 있어야 하는 것 | 처리 기준을 규정집에서 찾아야 한다 |
| [Sandbox](./glossary.html#sandbox) | 파일을 열어 전부 읽는다 | **1,000행 두 개를 맞춰 볼 방법이 없다** |

29번에서 본 것이 다음 랩의 문제입니다. **결과는 나오는데 양식이 사람마다 다릅니다.**
